# Student Persistence and Dropout

A machine-learning study focused on identifying students at risk of dropping out. The notebook covers data exploration, feature preparation, class imbalance, model comparison, nested cross-validation, and interpretation of the final model.

## Result

The selected pipeline uses L1-regularized logistic regression with random oversampling. It achieved an F1-score of **0.8067** on the held-out test set, compared with **0.7924** on the training set.
