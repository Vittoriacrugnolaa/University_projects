# Dataset

`student_data.csv` is the **Predict Students' Dropout and Academic Success** dataset from the UCI Machine Learning Repository.

- Records: 4,424 students
- Predictors: 36
- Target: `Dropout`, `Enrolled`, or `Graduate`
- Source: https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success
- DOI: https://doi.org/10.24432/C5MC89
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- SHA-256: `aee19b855044abab3d88d97c23acce7c7724061f4d9f8e3df806a3f93113069a`

Citation:

> Realinho, V., Vieira Martins, M., Machado, J., & Baptista, L. (2021). Predict Students' Dropout and Academic Success [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5MC89

The notebook keeps `Dropout` as the positive class and combines `Graduate` and `Enrolled` into the non-dropout class.
